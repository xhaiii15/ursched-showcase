# Responsible Security Reporting

If you believe you have found a security issue in the live UrSched application, please report it privately to [charliemelorin00@gmail.com](mailto:charliemelorin00@gmail.com). Include a concise description, the affected user-facing area, and enough detail to help assess the issue. Do not include passwords, tokens, or other sensitive information in a report.

Please do not test with real user data, access another person's account, disrupt the service, or publicly disclose a suspected issue before it has been reviewed.

The maintainer aims to acknowledge reports within five business days where possible. Further updates will depend on the report's scope and the time needed to investigate.

This policy is for the live application. This public repository contains documentation and media only.
