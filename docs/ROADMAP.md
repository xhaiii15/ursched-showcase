# Roadmap

This roadmap is directional, not a delivery commitment. Priorities and timing may change as the product evolves.

## Now

- Refine calendar readability and accessibility across month and agenda views.
- Continue improving feedback during event creation and conflict review.

## Next

- Make onboarding and reminder setup clearer.
- Improve guidance for first-time users creating events with natural language.

## Later

- Explore optional calendar integrations.
- Consider richer planning views while keeping the core calendar approachable.
