# Features

UrSched brings common scheduling tasks into one calendar experience. The descriptions below reflect the live product's public-facing feature set; they avoid implementation details.

## Natural-language event creation

Describe an event in a sentence, such as “Lunch with Ana tomorrow at 12:30.” UrSched uses the request to create a calendar event. The public landing page also notes that overlapping events are flagged before saving.

**Usage:** enter a natural-language event in the app, review the result, then save it.

## Month and agenda views

Use the month view to scan the wider schedule and select a day to see its agenda. Event status is visually distinguished as upcoming, ongoing, or past.

**Usage:** choose a day in the month overview to focus on that day's events.

## Conflict checks

Overlapping events are flagged before an event is saved, helping users catch scheduling clashes.

**Usage:** review any conflict notice while creating an event and adjust the schedule if needed.

## Reminders

Reminders help keep upcoming plans visible.

**Usage:** configure reminders in the live app where available. Do not use this showcase to publish account-specific reminder settings.

## Themes

The product supports light and dark appearance modes.

**Usage:** use the theme control in the app to change appearance.
